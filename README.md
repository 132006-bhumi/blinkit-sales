# 📊 Blinkit Sales Dashboard – Power BI Project
![Blinkit Logo](https://github.com/132006-bhumi/blinkit-sales/blob/main/Blinkit%20logo.jpeg)
# 🔍 Overview
This Power BI project presents an interactive dashboard analyzing the sales data of Blinkit, India’s last-minute delivery app. The dashboard provides key insights into sales performance, item categories, outlet types, fat content segmentation, outlet establishment trends, and regional sales breakdown. The aim is to assist business stakeholders in understanding where sales are concentrated, how different outlet and item types perform, and what influences average sales and ratings.
